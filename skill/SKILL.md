# 

## Goal
Generate a similarity report between two models generated by two provided open-api-spec.yml using openapi 3.0


## Step
1. Ask user for two repositories, the branches if the repository is same, and folder location of the yaml files
2. Checkout the two sources codes and label them as source1 and source2
3. Write a common pom.xml with openapi-maven-plugin generatior for openapi 3.0
4. Validate the two openapi spec.yml and generate two validation reports in html for the source code, list all the issues and recommended fixes and suggestions
5. Ask user to review the html files
6. In case user agrees, apply all the fixes and generate a report of all the fixes applied to the two repos
7. Now generate the two models and compare model classes which are generated for equivalence.
8. Generate the equivalence report.
